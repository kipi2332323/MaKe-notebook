# 马克笔记

用原生 HTML、CSS 和 JavaScript 编写的双栏笔记应用，无需安装依赖、无需联网。

## 使用

直接用 Chrome、Edge 或其他现代浏览器打开 `index.html`。

- 左侧选择、搜索笔记，切换全部 / 收藏，按编辑时间、创建时间或标题排序。
- 右侧直接修改标题和正文，每次输入都会自动保存到当前浏览器的 localStorage。
- 支持新建、收藏、TXT 导出、删除确认和撤销最近一次删除。
- `Alt + N` 新建，`Ctrl / Command + S` 保存。
- 窄屏下点击左上角按钮展开笔记列表。

正文为纯文本。数据只保存在当前浏览器，不跨设备同步；清除浏览器数据、换浏览器或移动 HTML 文件可能使原有笔记不可见，重要内容请使用右上角导出按钮备份。撤销仅在当前页面会话有效，可撤销最近一次删除。多窗口同时修改时，旧窗口会暂停保存并提示先导出再刷新，避免覆盖新内容。

## 测试

自动化测试使用 Playwright 驱动 Chromium 内核浏览器（本机优先使用 Edge），在隔离的浏览器环境中执行，不修改日常浏览器的笔记。

运行：`node tests/notes.test.cjs`。需要环境中提供 `playwright` 包与对应 Chromium。测试脚本也可使用本机 Codex 自带运行库，无需给应用安装任何依赖。

测试覆盖新建编辑、自动保存与刷新恢复、切换笔记、搜索、收藏、排序、导出文件内容、删除取消与撤销、空状态、恶意 HTML 的纯文本处理、快捷键、移动端布局、存储配额异常、损坏数据保护和多窗口冲突保护。

运行结果保存在 `tests/results.json`，桌面和手机截图分别为 `tests/desktop.png` 与 `tests/mobile.png`。
